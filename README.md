# 自律獎勵表 - 兒童院舍逐日追蹤版

兒童院舍自律獎勵計劃網頁，支援四位小朋友逐日打卡、跨日累積貼紙、兌換 30 分鐘電子娛樂時間、扣減原因記錄及交更報告。

## 永久網址（開啟 GitHub Pages 後）

**https://wangtung92-lab.github.io/zilv-jiangli-biao/**

## 如何啟用 GitHub Pages（只需一次）

1. 開啟這個 repo：https://github.com/wangtung92-lab/zilv-jiangli-biao
2. 點擊上方 **Settings**
3. 左邊選 **Pages**
4. **Source** 選 **Deploy from a branch**
5. Branch 選 **main**，Folder 選 **/ (root)**
6. 點 **Save**

等約 1-2 分鐘，重新敷載上面的網址就可以正常使用。

資料會存在每個使用者的瀏覽器 localStorage，不會上傳到任何伺服器。
